# Model output

Model results from the MODFLOW 6 Monte Carlo ensemble. All files are generated by `11_MODFLOW_Model_Setup_and_Monte_Carlo_Analysis.py` and read by `22_Postprocessing_Analyse_and_Plot_Model_Output.py`. And a directory to store temporary MODFLOW files, which are removed after each run to save disk memory.

```
2_model_output/
└── model_output_data/
    └── <run_name>/
        ├── overview/
        ├── budget/
        ├── median_heads/
        ├── heads_per_period/
        └── GW_SW_per_period/
└── temp_MODFLOW_workspaces/
    └── <run_name>/

```
